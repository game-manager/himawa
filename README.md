# HIMAWA

中高生が、仲の良い友達へ毎回「今ひま？」と聞かなくても、放課後の“遊べそうな気配”をアバターで確認できる招待制Webアプリです。

> Status: MVP development

**Beta:** https://game-manager.github.io/himawa/

Firebase Hosting版：https://himawa-social-2026.web.app

## コンセプト

**「ひま？」って聞く、その前に。**

正確な位置情報や行動履歴ではなく、「いま声をかけてもよいか」を期限付きステータスで共有します。友達を中心にしつつ、24時間で消える短文の「広場」と招待制グループで、ゆるく交流できる設計です。いいね数、ランキング、写真・動画、リポストは設けません。

## MVP

- メール認証とプロフィール
- パーツを組み合わせる簡易アバター
- 自由文・公開範囲・期限を選べるステータス
- 招待URLと相互承認
- 友達の状態を並べるウィジェット風ボード
- 定型Poke
- 相互の友達だけで使えるDM
- 24時間で消える短文の「広場」とフォロー
- 招待コード制グループとグループ限定ステータス
- 友達解除、ブロック、通報、退会
- ホーム画面へ追加できるPWA

### ステータス

ステータスはプリセットではなく60文字までの自由文です。絵文字、30分〜4時間の表示時間、公開範囲（友達・フォロワー・全体・選択したグループ）を指定できます。時間が来ると自動で失効します。

## MVPに含めないもの

- GPS・位置情報の収集
- バックグラウンドでの行動判定
- 音声通話
- 写真・動画の投稿
- 公開ユーザー検索
- ゲーム連携
- 課金、広告
- ネイティブOSウィジェット

Web版では、ホーム画面のPWAアイコンから友達ボードを直接開く体験を提供します。本物のOSウィジェットは、利用継続を検証してネイティブアプリ化する段階で検討します。

## 安全・プライバシー方針

- 招待制・相互承認を基本とする
- 正確な位置、学校名、住所、生年月日を収集しない
- ステータスの公開範囲を本人が毎回選択できる
- DMは相互承認した友達に限定する
- 広場は短文のみ・24時間で失効し、いいね数や拡散機能を持たない
- グループは招待コードを知る人だけが参加できる
- 画像、音声、位置情報をMVPで扱わない
- ステータスは自動失効させ、履歴を残さない
- ブロック後は相互の閲覧とPokeを即時停止する
- 広告SDKや第三者トラッカーを入れない

## ローカル開発

```bash
npm install
npm run dev
```

### 検証

```bash
npm run build
npm test
firebase emulators:exec --only firestore --project himawa-rules-test "npm run test:rules"
```

Firebaseの接続先は無料Sparkプランの `himawa-social-2026` です。Firestoreルールは、友達以外のプロフィール閲覧、コード一覧取得、ブロック後の閲覧を拒否します。

## 管理画面

管理者として登録されたアカウントは、設定画面の「管理画面を開く」またはURL末尾の `#admin` から運営画面へ移動できます。

- ユーザー検索とアプリ利用停止・解除
- 通報の対応済み・問題なし処理
- 広場投稿の削除
- グループ名と所有者の確認
- 管理操作の監査ログ

管理者でもDM本文やグループ内ステータスは閲覧できません。管理者の登録はクライアントから変更できない `admins/{uid}` で管理します。
