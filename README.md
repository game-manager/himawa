# After School Presence

中高生が、仲の良い友達へ毎回「今ひま？」と聞かなくても、放課後の“遊べそうな気配”をアバターで確認できる招待制Webアプリです。

> Status: Planning / MVP preparation

## コンセプト

**「ひま？」って聞く、その前に。**

正確な位置情報や行動履歴ではなく、「いま声をかけてもよいか」を期限付きステータスで共有します。公開投稿、フォロワー数、ランキングは設けず、相互承認した少人数の友達だけで使うことを想定しています。

## MVP

- メール認証とプロフィール
- パーツを組み合わせる簡易アバター
- 期限付きステータス
- 招待URLと相互承認
- 友達の状態を並べるウィジェット風ボード
- 定型Poke
- 友達解除、ブロック、通報、退会
- ホーム画面へ追加できるPWA

### 初期ステータス案

- いま遊べる
- ゲーム中
- 勉強中
- 移動中
- あとでならOK
- 今日はゆっくり
- 気配を消す

ステータスは一定時間後に自動で失効し、過去の行動履歴として原則保存しません。

## MVPに含めないもの

- GPS・位置情報の収集
- バックグラウンドでの行動判定
- 自由文チャット、音声通話
- 写真・動画の投稿
- 公開ユーザー検索
- ゲーム連携
- 課金、広告
- ネイティブOSウィジェット

Web版では、ホーム画面のPWAアイコンから友達ボードを直接開く体験を提供します。本物のOSウィジェットは、利用継続を検証してネイティブアプリ化する段階で検討します。

## 技術構成（予定）

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Web App Manifest / Service Worker

### Backend / Infrastructure

- Supabase Auth
- Supabase PostgreSQL + Row Level Security
- Supabase Realtime
- Cloudflare Pages
- GitHub Actions

無料枠を利用し、MVPの追加運用費を0円に抑える方針です。

## 安全・プライバシー方針

- 招待制・相互承認を基本とする
- 正確な位置、学校名、住所、生年月日を収集しない
- 友達関係やステータスを一般公開しない
- 自由文、画像、音声をMVPで扱わない
- ステータスは自動失効させ、履歴を残さない
- ブロック後は相互の閲覧とPokeを即時停止する
- 広告SDKや第三者トラッカーを入れない
